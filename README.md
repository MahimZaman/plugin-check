# Plugin Check (PCP)

Check a WordPress plugin against WordPress.org directory requirements and development practices.

This repository contains a copy of the plugin distribution by the WordPress Performance Team and Plugins Team. [Upstream plugin page](https://wordpress.org/plugins/plugin-check/)

## Requirements

WordPress 6.3+, PHP 7.4+

## Installation and use

1. Place the plugin files in `wp-content/plugins/plugin-check/`.
2. Activate **Plugin Check (PCP)** from **Plugins** in the WordPress dashboard.
3. Open **Tools → Plugin Check** and select the plugin to check.

See the [distribution README](readme.txt) for additional details.
